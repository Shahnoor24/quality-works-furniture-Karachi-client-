QUALITY WORKS FURNITURE — WEBSITE
================================

CONTENTS
- index.html       Main website structure and content
- styles.css       Responsive luxury styling and animation choreography
- script.js        Navigation, reveal animations, active section tabs, interactions

HOW TO PREVIEW
1. Extract the ZIP file.
2. Open index.html in Chrome, Edge, Firefox, or another modern browser.
3. An internet connection is required for Google Fonts and the remote Unsplash photography.

DESIGN
- Dark charcoal / warm ivory / walnut / champagne-gold palette
- Animated hero title and cinematic image reveal
- Scroll-triggered section choreography
- Animated navigation underline and mobile menu
- Responsive collection cards, inspiration gallery, and contact section
- WhatsApp and Facebook calls to action
